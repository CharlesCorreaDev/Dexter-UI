Navbar & Sidenav Unificados (Materialize, Bootstrap 6 & daisyUI)

Barras de navegação versáteis reunindo o layout em 3 zonas da daisyUI (.navbar-start, .navbar-center, .navbar-end), o sistema responsivo e Offcanvas do Bootstrap 6.0 (.navbar-expand-*, .navbar-nav-scroll, conteúdo externo .collapse) e o padrão completo do Materialize CSS (.nav-wrapper, .brand-logo, .nav-extended, barra de pesquisa e .sidenav), com 28 cores oficiais e Dark Mode.

1. Arquitetura em 3 Zonas (daisyUI: Start, Center & End)

Use .navbar-start, .navbar-center e .navbar-end para manter os links ou marca perfeitamente centralizados mesmo quando esquerda e direita possuem larguras diferentes. Combine com .navbar-floating ou .navbar-glass.

2. Bootstrap 6.0 Responsivo, Collapse & .navbar-nav-scroll

Com .navbar-expand-lg, a barra exibe o botão .navbar-toggler em telas menores e expande os itens no desktop. Adicione .navbar-nav-scroll com --dx-scroll-height para limitar a altura em listas longas colapsadas.

Adicione .nav-extended para incorporar uma segunda faixa inferior (.nav-content) com subtítulo ou abas transparentes (.tabs-transparent).

8. Exemplos de Código HTML & JS

HTML
<!-- 1. Estilo daisyUI (3 Zonas) -->
<nav class="navbar navbar-glass navbar-floating">
  <div class="navbar-start"><a class="navbar-brand" href="#">DexterUI</a></div>
  <div class="navbar-center"><ul class="navbar-menu"><li><a href="#">Home</a></li></ul></div>
  <div class="navbar-end"><a class="btn btn-sm btn-primary" href="#">Entrar</a></div>
</nav>

<!-- 2. Estilo Materialize Estendido + Sidenav -->
<nav class="nav-extended navbar-indigo">
  <div class="nav-wrapper">
    <a href="#" class="brand-logo">Logo</a>
    <a href="#!" data-target="mobile-nav" class="sidenav-trigger">Menu</a>
    <ul class="right hide-on-med-and-down">...</ul>
  </div>
  <div class="nav-content">...</div>
</nav>
