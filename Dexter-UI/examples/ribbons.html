Core UI CSS Puro 57 Variações 28 Cores + 5 Tamanhos

Ribbons & Faixas CSS (57 Estilos Modernos)

Catálogo modular em CSS puro dividido em 3 eixos independentes de classes: classe do formato (.ribbon-{formato} ou .ribbon-1...ribbon-57), classe de tamanho (.ribbon-size-xs a .ribbon-size-2xl / .ribbon-size-1...ribbon-size-6) e classe de cor (.ribbon-color-{cor} para todas as 28 cores oficiais + semânticas WCAG).

Dica: clique em qualquer cartão abaixo para copiar a combinação completa .ribbon .{formato} .ribbon-size-* .ribbon-color-*.

1. Classes de Tamanho (.ribbon-size-*)

Combine qualquer formato de ribbon com uma das 6 escalas dedicadas de tamanho (.ribbon-size-xs a .ribbon-size-2xl ou .ribbon-size-1 a .ribbon-size-6):

XS
.ribbon-size-xs
SM
.ribbon-size-sm
MD
.ribbon-size-md
LG
.ribbon-size-lg
XL
.ribbon-size-xl
2XL
.ribbon-size-2xl

HTML
<!-- Sintaxe modular: .ribbon + .{formato} + .ribbon-size-* + .ribbon-color-* -->
<div class="card ribbon-box p-4">
  <div class="ribbon ribbon-corner-tr ribbon-size-sm ribbon-color-red">NOVO</div>
  <h5>Plano Profissional</h5>
</div>

<!-- Medalha autônoma com tamanho e cor explícitos -->
