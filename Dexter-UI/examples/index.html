Introdução ao Dexter UI Framework

Framework CSS/JS moderno, leve e altamente escalável para Web e E-mail, projetado com design tokens nativos, conformidade estrita WCAG 2.1 AA/AAA e arquitetura bilíngue.

Sobre o Projeto

O Dexter UI foi concebido por Charles Corrêa para unificar o desenvolvimento frontend com rigor arquitetural, eliminando o inchaço de frameworks legados sem abrir mão da flexibilidade do Sass e das CSS Custom Properties modernas.

Grid de 14 Colunas

Divisão flexível por 1, 2, 7 e 14 colunas, ideal para dashboards, layouts simétricos e grids complexos.

28 Famílias de Cores

5 cores de tema + 23 cores estendidas, todas com escala tonal de 13 passos (025 a 975) geradas por algoritmo.

Instalação e Compilação

Clone o repositório e compile a distribuição CSS otimizada:

# Clone o repositório
git clone https://github.com/CharlesCorreaDev/Dexter-UI.git

# Instale dependências
npm install

# Compilar CSS distribuído (PostCSS + Sass)
npm run build

Os arquivos prontos para produção são gerados em Dexter-UI/dist/css/:

  • dexter.css – Versão expandida com source maps e separadores de seção.
  • dexter.min.css – Versão minificada e ultra leve para produção.
