Conteúdo Tipográfico (Prose)

Inspirado na mais recente especificação do Bootstrap 6.0 Content Prose e no ecossistema moderno de design, a classe .prose estiliza belamente textos longos, artigos de blog, saídas de Markdown/CMS e documentações técnicas sem precisar adicionar classes utilitárias a cada elemento HTML nativo.

1. Exemplo Completo (.prose)

Basta envolver o seu texto gerado dinamicamente em <article class="prose">. Todos os elementos nativos (<p>, <h1>-<h6>, <blockquote>, <ul>, <code>, <pre>, <table>, <img>) recebem ritmo vertical impecável, largura ótima de leitura de 65 caracteres (65ch) e tipografia agradável:

Arquitetura Moderna de Sistemas e Design Systems Fluidos

A evolução dos frameworks modernos de CSS exige o equilíbrio perfeito entre flexibilidade visual, acessibilidade cognitiva WCAG 2.1 AAA e desempenho extremo sem dependências pesadas de JavaScript.

Ao construir interfaces ricas, o desenvolvedor frequentemente se depara com conteúdos gerados dinamicamente — como artigos redigidos em Markdown, posts de blog oriundos de um headless CMS ou saídas de editores ricos (WYSIWYG). Aplicar classes utilitárias manualmente em cada parágrafo torna-se impraticável.

Princípios Fundamentais de Leitura e Ergonomia

O comprimento da linha de texto (chamado de measure na tipografia editorial clássica) exerce impacto direto na fadiga ocular do leitor. Linhas que ultrapassam 80 caracteres forçam o olho a percorrer uma trajetória excessiva, aumentando as chances de o usuário perder o início da próxima linha.

A tipografia não existe apenas para exibir palavras na tela; ela existe para conduzir o pensamento do leitor sem fricção cognitiva.

Charles Corrêa, Lead Architect

Recursos Nativos Suportados

Veja a seguir a estilização automática aplicada a elementos comuns:

  • Hierarquia visual clara: Títulos calibrados com espaçamento proporcional superior e inferior.
  • Links com transição suave: Hyperlinks destacados com a transição canônica de 700ms ease-in-out do Dexter UI.
  • Marcadores temáticos: Marcadores estilizados automaticamente com a paleta oficial.
  • Entrada de teclado: Pressione Ctrl + Shift + P para abrir a paleta de comandos.

Também há suporte total a listas ordenadas sequenciais:

  1. Defina os tokens no arquivo _config.scss.
  2. Compile o pacote com npm run build.
  3. Inspecione os resultados no navegador com o tema desejado.

Código Inline e Blocos <pre>

O código inline é demarcado através de const engine = new DexterEngine(); com fundo contrastante sutil. Já blocos de código com múltiplos comandos utilizam preenchimento generoso e barra de rolagem horizontal automática:

// Exemplo de integração nativa com Dexter UI Prose
import { initProseEnhancer } from "@dexter-ui/core";

const article = document.querySelector(".prose");
if (article) {
  console.log("Tipografia fluida ativada com 65ch de largura máxima.");
}

Elementos Retráteis (<details>)

Clique para visualizar notas técnicas de compatibilidade

3. Controle de Largura de Leitura (.prose-narrow, .prose-wide, .prose-full)

Controle o measure (limite de caracteres por linha) para atender a diferentes objetivos de design e requisitos de acessibilidade cognitiva:

Ergonomia Cognitiva & TDAH (45ch)
Leitura Concentrada (.prose.prose-narrow)

A classe .prose-narrow restringe a linha a 45 caracteres. Estudos ergonômicos e a matriz de acessibilidade cognitiva comprovam que colunas mais estreitas reduzem drasticamente a distração e a dispersão em leitores com TDAH ou fadiga visual.

Padrão Otimizado (65ch)
Largura Padrão (.prose)

O valor canônico de 65 caracteres proporciona o equilíbrio ideal entre aproveitamento de espaço e facilidade de localização do início da linha pelo olho humano.

Largura Expandida / Completa (.prose.prose-full)
Largura Total (.prose.prose-full)

Remove a restrição de largura máxima (max-width: none), permitindo que o texto preencha 100% da largura do contêiner pai no grid de 14 colunas.

6. Modo Escuro e Inversão (.prose-invert)

Quando o tema escuro estiver ativo (data-dx-theme="dark"), o .prose ajusta automaticamente seus tons. Você também pode forçar o modo escuro manualmente em um contêiner escuro aplicando .prose-invert:

Artigo com Inversão Forçada (.prose-invert)

Este painel possui fundo escuro permanente. A classe .prose-invert recalcula as variáveis de cor para garantir contraste de alto nível (WCAG AAA) contra o fundo preto ou chumbo.

O contraste correto em modo escuro previne a fadiga visual noturna.

Código inline adaptado: theme: "dark" com destaque em tom coral.
