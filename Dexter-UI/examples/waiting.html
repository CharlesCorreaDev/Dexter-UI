Diálogo de Espera e Progresso (WaitingFor)

Controlador modal nativo para operações assíncronas bloqueantes inspirado e compatível drop-in com ehpc/bootstrap-waitingfor (waitingDialog). Elimina jQuery e Bootstrap JS externos, oferecendo progresso determinado em tempo real, execução automática via Promise.run(), loaders integrados, botão de cancelamento opcional e suporte às 28 cores + Dark Mode.

4. Código de Uso & Compatibilidade Drop-in

// Compatível drop-in com ehpc/bootstrap-waitingfor (sem jQuery)
waitingDialog.show('Processando faturamento...', {
  dialogSize: 'm',
  progressType: 'success'
});

setTimeout(function () {
  waitingDialog.hide(function () {
    console.log('Diálogo encerrado');
  });
}, 1500);

// API moderna DexterWaiting com progresso determinado e Promise
await DexterWaiting.run(function (dialog) {
  dialog.progress(30, 'Enviando arquivos...');
  return new Promise(function (resolve) {
    setTimeout(function () {
      dialog.progress(100, 'Concluído!');
      resolve('OK');
    }, 800);
  });
}, 'Preparando envio...', {
  progressType: 'indigo',
  showPercent: true,
  progress: 0,
  loader: 'loader-ring'
});
