Carrossel & Slider Multi-Item (Carousel Multi)

Suíte nativa e completa de carrossel multi-itens e slider de cartões inspirada em bootstrap5-carousel-multi. Diferente dos carrosséis padrão que saltam telas inteiras de forma rígida, o Dexter Carousel desliza suavemente 1 cartão por vez, oferece suporte completo a gestos touch swipe em dispositivos móveis, transições CSS fluidas, autoplay com pausa no hover, controles externos e integração total com as 28 cores oficiais do Dexter UI e Dark Mode.

1. Multi-Item Card Slider (Deslizamento Suave 1 a 1)

Exibe múltiplos cartões por tela de forma responsiva (1 no celular, 2 em tablets, 3 em telas médias e 4 em desktops). Ao clicar nas setas ou arrastar no touch, avança 1 cartão de cada vez com transição fluida:

6. API JavaScript & Inicialização Programática

O Dexter Carousel suporta inicialização automática via data-dx-carousel ou via código JavaScript com a classe DexterCarousel:

JavaScript 
// Inicialização programática via JavaScript
const carousel = new DexterCarousel('#meuCarrossel', {
  itemsToScroll: 1,      // Quantos itens avançar a cada clique
  gap: 16,               // Espaçamento entre os cartões em px
  autoplay: true,        // Ativa transição automática
  interval: 5000,        // Intervalo do autoplay em milissegundos
  pauseOnHover: true,    // Pausa no hover do mouse
  touch: true            // Habilita gestos de arrasto e touch swipe
});

// Métodos de controle
carousel.next();         // Avança 1 cartão
carousel.prev();         // Volta 1 cartão
carousel.slideTo(2);     // Vai para o índice desejado
carousel.pause();        // Pausa autoplay
carousel.cycle();        // Retoma autoplay
