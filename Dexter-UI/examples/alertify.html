AlertifyJS para Dexter UI (Alert, Confirm, Prompt, Notifier & Factory)

Suíte completa 100% Vanilla JS inspirada e compatível drop-in com alertifyjs.com. Inclui diálogos arrastáveis, maximizáveis e redimensionáveis, tema padrão Dexter e modo Bootstrap 5/6, Notifier em 6 posições com suporte às 28 cores e Dialog Factory (alertify.dialog()) com herança e múltiplos botões.

Registro de Eventos (alertify): Clique em qualquer exemplo abaixo para testar callbacks e retornos.

1. Alert, Confirm, Prompt & Tema Bootstrap

Alterne entre o visual padrão do Dexter UI e o tema Bootstrap (alertify.defaults.theme), além da cor de destaque entre as 28 opções da paleta.

2. Arrastar, Maximizar, Redimensionar, Frameless & Transições

Todos os diálogos permitem arrastar pelo cabeçalho (movable), alternar tela cheia (maximizable) e usar as 4 animações nativas de entrada:

3. Notificador Flutuante (6 Posições & 28 Cores)

Dispare notificações empilháveis em qualquer uma das 6 posições de tela com suporte a auto-ocultamento, botão fechar opcional e cores da paleta oficial:

4. Dialog Factory (alertify.dialog())

Registre novos tipos de diálogo reutilizáveis do zero (genericDialog) ou estendendo um diálogo nativo como 'confirm' (multiActionConfirm com 3 botões).

5. Exemplos de Uso (API JS)

JS
// 1. Alert, Confirm & Prompt (Zero Dependências)
alertify.alert('Aviso', 'Operação concluída com sucesso!', function () {
  alertify.success('Confirmado pelo usuário');
});

alertify.confirm('Excluir Registro', 'Deseja realmente excluir este item?',
  function () { alertify.success('Registro excluído!'); },
  function () { alertify.error('Ação cancelada.'); }
);

alertify.prompt('Renomear Projeto', 'Informe o novo nome:', 'Dexter UI',
  function (evt, value) { alertify.success('Novo nome: ' + value); },
  function () { alertify.message('Cancelado'); }
);

// 2. Tema Bootstrap & Posicionamento do Notifier
alertify.defaults.theme.ok = 'btn btn-primary';
alertify.defaults.theme.cancel = 'btn btn-secondary';
alertify.defaults.theme.input = 'form-control';
alertify.set('notifier', 'position', 'top-right');

// 3. Custom Dialog Factory (estendendo 'confirm')
alertify.dialog('multiActionConfirm', function () {
  return {
    main: function (title, message, onChoice) {
      this.setHeader(title);
      this.setContent(message);
      this.__onChoice = onChoice;
    },
    setup: function () {
      return {
        buttons: [
          { text: 'Descartar', key: 68, className: 'btn btn-outline-danger', scope: 'auxiliary' },
          { text: 'Cancelar', key: 27, themeKey: 'cancel' },
          { text: 'Salvar', key: 13, themeKey: 'ok' }
        ]
      };
    },
    callback: function (closeEvent) {
      if (this.__onChoice) this.__onChoice(closeEvent.button.text);
    }
  };
});
