Consentimento de Cookies (LGPD / GDPR)

Painel interativo e controlador zero-dependência baseado em shaack/bootstrap-cookie-consent-settings. Oferece 3 modos de layout (Modal Centralizado, Barra Inferior e Card Flutuante), seleção granular por categorias com acordeão nativo, internacionalização embutida (pt, en, es, de), persistência em Cookie Query String + LocalStorage e ativação automática de scripts declarativos.

3. Armazenamento Query String & Ativação de Scripts

Formato Compatível Backend (HTTP Query String)

Seguindo exatamente o formato de shaack/bootstrap-cookie-consent-settings, as preferências são gravadas no cookie cookie-consent-settings como query string URL-encoded:

necessary=true&statistics=true&marketing=false&personalization=true
Scripts Bloqueados até o Consentimento

Tags declaradas com type="text/plain" e data-cookie-category="statistics" permanecem inativas até o usuário aprovar a respectiva categoria no diálogo, sendo ativadas em tempo real pelo controlador.

4. Código de Uso & Compatibilidade Drop-in

// Inicialização nativa (ou use o alias BootstrapCookieConsentSettings)
var cookieConsent = new DexterCookieConsent({
  privacyPolicyUrl: '/privacidade',
  legalNoticeUrl: '/aviso-legal',
  lang: 'pt',
  layout: 'modal', // 'modal' | 'bar-bottom' | 'floating-bottom-start' | 'floating-bottom-end'
  color: 'indigo', // qualquer uma das 28 cores oficiais
  postSelectionCallback: function (settings) {
    console.log('Consentimento atualizado:', settings);
  }
});

// Leitura programática e reabertura sob demanda
if (cookieConsent.isAllowed('statistics')) {
  console.log('Analytics liberado!');
}
cookieConsent.showDialog();
<!-- Script ativado automaticamente somente após consentimento em "statistics" -->
<script type="text/plain" data-cookie-category="statistics">
  console.log('Script analítico autorizado pelo usuário');
</script>

<!-- Botão declarativo para reabrir preferências -->
<button type="button" class="btn btn-outline-secondary btn-sm" data-dx-cookie-open>
  Gerenciar Cookies
</button>
