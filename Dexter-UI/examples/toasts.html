Notificações Toast & Snackbars

Suíte completa de notificações reativas e não invasivas para o Dexter UI, inspirada e aprimorada a partir do chrisgo/bootstrap5-toast e Script47/Toast. Elimina a dependência de jQuery com o controlador nativo DexterToast, trazendo grid de 9 quadrantes, barra de progresso temporal animada (countdown), pausa ao passar o mouse, avatares/ícones SVG integrados, botões de ação com callbacks, snacks compactos em pílula, suporte a todas as 28 cores e Dark Mode.

1. Grid de Posicionamento em 9 Quadrantes

Dispare notificações em qualquer ponto da tela através do atributo position. O contêiner é criado e gerenciado automaticamente pelo DexterToast:

Teste Interativo dos 9 Quadrantes
JavaScript 
// Disparo em qualquer uma das 9 posições
DexterToast.show({
  title: 'Alerta de Sistema',
  content: 'Sincronização em segundo plano concluída com sucesso.',
  position: 'top-right', // 'top-left' | 'top-center' | 'top-right' | 'middle-center' | 'bottom-right' ...
  duration: 4000
});

2. Tipos Semânticos & Barra de Countdown Animada

Atalhos dedicados com ícones SVG integrados, cores temáticas oficiais e barra de progresso temporal com pausa automática ao passar o mouse:

Disparo Rápido por Tipo Semântico

* Passe o mouse sobre a notificação para pausar a contagem regressiva da barra de progresso.

JavaScript 
// Métodos de atalho com ícone e cores pré-configuradas
DexterToast.success('Operação Concluída', 'Seus dados foram salvos na nuvem.');
DexterToast.error('Falha de Conexão', 'Não foi possível contatar o servidor.');
DexterToast.warning('Espaço em Disco', 'Seu limite de armazenamento está em 92%.');
DexterToast.info('Atualização Disponível', 'Uma nova versão do Dexter UI foi lançada.');

3. Variantes Soft Tonal & Vidro Fosco (Glassmorphism)

Estilos modernos com fundos suaves, borda lateral tonal e efeito de vidro fosco translúcido (Glassmorphism):

Temas Visuais Avançados
JavaScript 
// Tema Soft com destaque lateral na paleta oficial
DexterToast.show({
  theme: 'soft',
  color: 'coral',
  title: 'Campanha Ativa',
  content: 'Os novos cupons foram gerados com sucesso.'
});

// Vidro Fosco translúcido com backdrop-filter blur
DexterToast.show({
  theme: 'glass',
  title: 'Glassmorphism Toast',
  content: 'Efeito visual refinado com desfoque de fundo.'
});

4. Snackbars Compactos em Formato Pílula (.toast-snack)

Notificações rápidas e discretas em formato arredondado de linha única, ideais para confirmações de ações:

Snackbars Rápidos
JavaScript 
// Snackbar compacto em formato pílula
DexterToast.snack('Link copiado para a área de transferência!', {
  type: 'success',
  position: 'bottom-center'
});

5. Toasts Interativos com Botões de Ação

Incorpore botões clicáveis com manipuladores de evento diretamente no corpo do Toast (ex: "Desfazer", "Visualizar", "Reconectar"):

Ação de Desfazer (Undo)
JavaScript 
DexterToast.show({
  title: 'Item Removido',
  content: 'A conversa foi movida para a lixeira.',
  duration: 8000,
  actions: [
    {
      text: 'Desfazer',
      class: 'btn btn-sm btn-primary',
      onClick: function(toastEl) {
        DexterToast.hide(toastEl);
        DexterToast.snack('Ação desfeita com sucesso!', { type: 'success' });
      }
    },
    {
      text: 'Ver Lixeira',
      class: 'btn btn-sm btn-outline-secondary',
      onClick: function() {
        console.log('Navegar para lixeira...');
      }
    }
  ]
});
