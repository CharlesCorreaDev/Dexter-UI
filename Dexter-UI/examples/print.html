CSS de Impressão (@media print)

Folha de estilos e utilitários projetados para gerar relatórios, faturas e páginas impressas impecáveis, economizando tinta e organizando a quebra de páginas.

Documento Impresso via Dexter UI Framework
Gerado em: · Autor: Charles Corrêa

1. Como Usar

O CSS de impressão do Dexter UI está disponível de duas maneiras:

Incluso no Pacote Geral

Já embutido dentro de dexter.css e dexter.min.css via @media print. Não requer nenhum arquivo adicional.

<link rel="stylesheet" href="dexter.min.css">

Arquivo Autônomo (Standalone)

Disponível em dist/css/dexter-print.min.css para quem prefere carregar o CSS condicionalmente apenas ao imprimir.

<link rel="stylesheet" href="dexter-print.min.css" media="print">

2. Economia de Tinta e Alto Contraste

Por padrão, todo o conteúdo impresso tem sombras e cores de fundo puramente decorativas removidas, forçando texto em preto absoluto sobre papel branco com tipografia em 11pt (tamanho padrão de leitura em papel):

  • Zero desperdício de tinta: fundos coloridos viram transparentes e sombras são removidas.
  • Margens padronizadas: @page { margin: 15mm 20mm; } otimizado para papel A4 e Carta.
  • Linhas órfãs e viúvas protegidas: parágrafos e citações mantêm um mínimo de 3 linhas no início e final da página (orphans: 3; widows: 3;).

3. Controle de Visibilidade na Impressão

Oculte elementos de navegação na impressão ou exiba informações exclusivas para o papel:

Classe Efeito na Tela Efeito no Papel (@media print)
.no-print ou .d-print-none Visível normalmente Oculto (display: none)
.print-only ou .d-print-only Oculto (display: none) Visível (display: block)
.d-print-inline Mantém estilo de tela Exibe como inline
.d-print-flex Mantém estilo de tela Exibe como flexbox
Elemento com .no-print
Aparece na tela, mas desaparece completamente ao imprimir!
Elemento com .print-only
Visível apenas no papel / pré-visualização de impressão!

4. Destino de Links no Papel

Como no papel não é possível clicar em hyperlinks, o Dexter UI imprime automaticamente a URL de destino de links externos entre parênteses:

Visite o repositório oficial no GitHub do Dexter UI para acompanhar o código-fonte.

Se você tem um link que não deve mostrar a URL no papel, adicione a classe .no-print-url: Website Charles Corrêa (sem URL impressa).

Abreviações mostram o significado: W3C e CSS.

5. Controle de Quebras de Página

Use classes atômicas para forçar ou evitar quebras de página em relatórios extensos:

Classe Utilitária Propriedade CSS Paged Media Uso Típico
.break-before-page
alias .page-break-before		 break-before: page; Força o início do elemento em uma nova folha impressa (ex: novos capítulos ou seções de contrato).
.break-after-page
alias .page-break-after		 break-after: page; Força que o próximo elemento vá para a folha seguinte.
.break-inside-avoid
alias .page-break-avoid		 break-inside: avoid; Evita que o bloco seja cortado no meio por uma virada de página (tabelas, cards, assinaturas).

7. Preservação Exata de Cores (.print-color-exact)

Quando for estritamente necessário imprimir cores de fundo (como em gráficos, crachás, selos ou logos), use a classe .print-color-exact:

Sem preservação (Padrão de Tinta)
Fundo colorido na tela, fundo transparente no papel.
Com .print-color-exact
Mantém a cor exata mesmo no papel impresso.
