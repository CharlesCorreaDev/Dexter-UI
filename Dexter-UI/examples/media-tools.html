Utilitários Interativos Autosize.js Zoom (4 Modos) Wheelzoom Scroll & Pan

Autosize, Zoom & Wheelzoom (Zero Dependências)

Portagem fiel em Vanilla JS puro dos três utilitários de entrada e manipulação de imagem de Jack Moore (autosize, zoom e wheelzoom), integrados ao Dexter UI sem jQuery, com suporte a eventos customizados e controles responsivos.

1. Textarea Autosize (autosize())

Ajusta automaticamente a altura da caixa de texto conforme você digita ou altera o conteúdo programaticamente com autosize.update().

Altura: auto

2. Lupa & Pan em Imagens (DexterZoom — 4 Modos)

Reproduz os quatro modos do jquery-zoom em CSS + Vanilla JS puro: mouseover, grab, click e toggle.

Modo 1: mouseover (Passe o cursor)

Ampliação instantânea 2x ao entrar com o mouse.

Hover (2x)
Modo 2: grab (Clique e segure)

Pressione o botão do mouse e arraste para explorar.

Grab (2x)
Modo 3: click (Clique para ativar)

Ativa no clique; sai ao clicar novamente ou deixar a área.

Click (2x)
Modo 4: toggle (Trava até novo clique)

Permanece ampliado mesmo ao mover o cursor para fora.

Toggle (2.2x)

3. Wheelzoom por Scroll & Arrasto (wheelzoom())

Use a roda do mouse sobre a planta abaixo para ampliar no ponto exato do cursor, arraste para navegar e clique duas vezes (ou use os botões flutuantes) para resetar.

1.0x

4. Exemplos de Uso (JS & Atributos HTML)

JS
// 1. Autosize (expansão automática de textarea)
autosize(document.querySelectorAll('textarea.dx-autosize'));
// Após alterar textarea.value via script:
autosize.update(textarea);
// Para remover listeners:
autosize.destroy(textarea);

// 2. DexterZoom (modos: 'mouseover' | 'grab' | 'click' | 'toggle')
zoom('#minhaFoto', { on: 'grab', magnify: 2 });

// 3. Wheelzoom (scroll focalizado no cursor + arrasto)
wheelzoom(document.querySelectorAll('img.zoomable'), { zoom: 0.2, maxZoom: 4 });
// Eventos e métodos nativos:
wheelzoom.reset('#minhaPlanta');
