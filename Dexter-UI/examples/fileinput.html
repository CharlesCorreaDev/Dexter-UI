Upload & Pré-visualização de Arquivos

Suíte completa de seleção, pré-visualização visual e upload de arquivos para o Dexter UI, inspirada e aprimorada a partir do Krajee Bootstrap FileInput (plugins.krajee.com/file-input). Elimina a dependência de jQuery com o controlador nativo DexterFileInput, trazendo área drag-and-drop responsiva, miniaturas com aspect ratio para imagens, PDFs e documentos, modal de zoom (lightbox), barra de progresso, modo compacto horizontal, modo avatar e integração com as 28 cores oficiais do sistema.

1. Área Drag-and-Drop Completa com Galeria de Miniaturas

Área de soltura interativa com suporte a seleção múltipla, arrastar e soltar (drag-and-drop), pré-visualização em tempo real de imagens e documentos, botão de exclusão individual, zoom em lightbox e barra de ações globais:

Arraste ou Selecione Múltiplos Arquivos
HTML / JS 
<!-- Dropzone Completo com Inicialização Automática -->
<input type="file" class="file-input" multiple data-dx-fileinput>

<!-- Ou Inicialização Programática via JavaScript -->
<script>
  const uploader = new DexterFileInput(document.querySelector('#meuInput'), {
    maxFileSize: 10 * 1024 * 1024, // 10 MB
    maxFileCount: 5,
    onFileSelect: (files) => console.log('Arquivos selecionados:', files),
    onUploadSuccess: (res) => dxToast.success('Upload Concluído', 'Arquivos enviados!')
  });
</script>

2. Modo Compacto Horizontal (Simple File Picker)

Ideal para formulários compactos ou barras de anexos, onde o espaço vertical é limitado. Exibe botão de navegação, nome do arquivo selecionado e botão de limpar:

Seletor Compacto em Linha
HTML 
<!-- Seletor Compacto via data-dx-mode="compact" -->
<input type="file" data-dx-fileinput data-dx-mode="compact">

<!-- Com cor temática oficial (ex: Coral) -->
<input type="file" data-dx-fileinput data-dx-mode="compact" data-dx-color="coral">

3. Modo Avatar / Foto de Perfil Circular

Dropzone circular projetado especificamente para seleção de fotos de usuário, com overlay suave de câmera no hover e atualização instantânea da miniatura:

Foto de Perfil do Usuário

Clique sobre a foto ou arraste uma nova imagem para atualizar seu avatar.

JPG, PNG ou WebP Até 5MB
HTML 
<!-- Modo Avatar Circular com Preview Instantâneo -->
<input type="file" accept="image/*" data-dx-fileinput data-dx-mode="avatar">
