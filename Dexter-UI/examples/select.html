Select Moderno (SelectPicker)

Transformação nativa zero-dependência para elementos <select>, inspirada no clássico bootstrap-select (SnapAppointments), oferecendo busca em tempo real, seleção múltipla com contagem personalizada, caixa de ações rápidas, subtextos descritivos, ícones, limites de escolha e 28 cores oficiais.

1. Select Básico com Estilização Moderna

Basta adicionar a classe .selectpicker (ou o atributo data-dx-select) a qualquer <select> nativo para convertê-lo instantaneamente em um controle elegante com opções zebradas:

HTML 
<!-- Select Básico via classe .selectpicker -->
<select class="selectpicker" title="Escolha um idioma...">
  <option value="pt-br" selected>Português (Brasil)</option>
  <option value="en-us">Inglês (Estados Unidos)</option>
  <option value="es-es">Espanhol (Espanha)</option>
</select>

2. Busca em Tempo Real (Live Search)

Adicione data-live-search="true" para incluir um campo de pesquisa instantâneo com filtragem flexível insensível a maiúsculas e acentos, e mensagem de resultado não encontrado:

HTML 
<select class="selectpicker" data-live-search="true" data-live-search-placeholder="Filtrar país...">
  <option value="BR">Brasil</option>
  <option value="PT">Portugal</option>
  <option value="JP">Japão</option>
</select>

3. Seleção Múltipla & Formatos de Contagem

Transforme <select multiple> em uma interface rica com checkmarks de seleção e formatação inteligente de texto via data-selected-text-format="count > 2":

HTML 
<!-- Se mais de 2 itens forem marcados, exibe "3 de 6 itens marcados" -->
<select class="selectpicker" multiple data-selected-text-format="count > 2" data-count-selected-text="{0} de {1} itens marcados">
  <option value="auth" selected>Autenticação 2FA</option>
  <option value="audit" selected>Logs de Auditoria</option>
  <option value="billing" selected>Módulo Financeiro</option>
  <option value="reports">Relatórios em PDF</option>
</select>

4. Caixa de Ações em Lote (data-actions-box="true")

Adiciona botões de atalho rápido no topo do menu para Selecionar Todos e Desmarcar Todos com um único clique:

HTML 
<select class="selectpicker" multiple data-actions-box="true" data-select-all-text="Selecionar Todos" data-deselect-all-text="Desmarcar Todos">
  <option value="1">Opção 1</option>
  <option value="2">Opção 2</option>
</select>

5. Subtextos e Informações Adicionais (data-subtext)

Adicione data-subtext="..." em qualquer <option> para exibir detalhes complementares (como fabricantes, descrições breves ou preços) sem poluir o título principal:

HTML 
<select class="selectpicker">
  <option data-subtext="Heinz">Ketchup</option>
  <option data-subtext="Hellmann's">Maionese</option>
</select>

11. Controle Programático via JavaScript

Acesse a instância com select.dexterSelect ou DexterSelect.getInstance(select) para alterar valores, selecionar todos ou atualizar opções dinamicamente:

JavaScript 
// Instanciar ou obter instância
const selectEl = document.querySelector('#meuSelect');
const ds = DexterSelect.getOrCreateInstance(selectEl);

// Selecionar ou desmarcar todos
ds.selectAll();
ds.deselectAll();

// Definir e obter valores (compatível com jQuery .val())
ds.val(['prod', 'stage']);
console.log(ds.val());

// Re-renderizar após adicionar novas <option> dinamicamente
ds.refresh();
