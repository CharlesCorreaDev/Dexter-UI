Acordeão & Colapso (Accordion)

Suíte nativa zero-dependência para painéis expansíveis e sanfonas de conteúdo, inspirada no Bootstrap 5 e no accordion-bs5 de Hilton Muccillo, com botões de abrir/fechar todos, modos flush, cartões separados, ícones à esquerda, alternador mais/menos e suporte completo às 28 cores oficiais do Dexter UI.

1. Acordeão Clássico com Exclusão Mútua

Ao clicar em um item, o painel selecionado se expande suavemente com transição acelerada por hardware e todos os outros itens se fecham automaticamente através do atributo data-dx-parent:

O Dexter UI é um framework de design system moderno, modular e acessível para web e e-mail. Construído sem nenhuma dependência de jQuery ou bibliotecas externas pesadas, ele oferece componentes Vanilla JS ultraleves e tokens nativos em variáveis CSS com tema escuro automático.

Ao definir data-dx-parent="#meuAcordeao" nos containers .accordion-collapse, o controlador DexterCollapse monitora os itens ativos e executa a transição de recolhimento dos demais itens abertos de forma sincronizada.

Sim! O padrão WAI-ARIA Accordion é plenamente atendido com atualização automática de aria-expanded="true/false", vínculos semânticos aria-controls e navegação por teclado completa via setas (↑ e ↓), Home e End.
HTML 
<div class="accordion" id="accordionExemplo">
  <div class="accordion-item">
    <h2 class="accordion-header" id="heading1">
      <button class="accordion-button" type="button" data-dx-toggle="collapse" data-dx-target="#item1" aria-expanded="true">
        Título da Sanfona 1
      </button>
    </h2>
    <div id="item1" class="accordion-collapse collapse show" data-dx-parent="#accordionExemplo">
      <div class="accordion-body">Conteúdo do item 1...</div>
    </div>
  </div>
</div>

9. Controle Programático via JavaScript

Controle qualquer acordeão ou colapso programaticamente através da API global dexter.Accordion e dexter.Collapse:

Conteúdo controlado via chamadas programáticas em JavaScript.

Você pode alternar qualquer item individualmente pelo índice ou seletor.
JavaScript 
// Instancia o Acordeão
const acc = new dexter.Accordion('#meuAcordeao');

// Abrir e fechar todos
acc.openAll();
acc.closeAll();

// Alternar item específico pelo índice
acc.toggle(0);

// Ou controlar um elemento .collapse individual
const collapse = dexter.Collapse.getOrCreateInstance('#meuColapso');
collapse.show();
collapse.hide();
collapse.toggle();
