Seleção Múltipla com Dropdown & Checkboxes

Suíte completa de seleção múltipla em menu suspenso para o Dexter UI, inspirada e aprimorada a partir do BsMultiSelect (github.com/DashboardCode/BsMultiSelect). Substitui menus de seleção convencionais por uma experiência corporativa rica com caixas de seleção integradas, agrupamento com <optgroup>, barra de ações (Selecionar Todos / Limpar), busca em tempo real com realce de texto, modo de resumo condensado (collapse), badges com botão de remoção, compatibilidade às 28 cores e Dark Mode.

1. MultiSelect Básico com Dropdown & Checkboxes

Converte nativamente qualquer <select multiple> em um campo de seleção múltipla com chips interativos no gatilho e caixas de seleção no menu suspenso:

Clique para abrir o dropdown, marque as caixas de seleção ou remova badges com ×.
HTML 
<!-- Select Múltiplo nativo com auto-inicialização data-dx-multiselect -->
<select multiple data-dx-multiselect data-dx-color="primary" placeholder="Selecione as opções...">
  <option value="react" selected>React</option>
  <option value="vue" selected>Vue.js</option>
  <option value="svelte">Svelte</option>
</select>

3. Modo Resumo Condensado (data-collapse-after="N")

Quando muitos itens são marcados, o modo condensado substitui a aglomeração de chips por uma badge limpa e elegante indicando o total selecionado (ex: 4 selecionados ou Todos selecionados):

Como há 4 itens selecionados e o limite configurado é 2, o gatilho exibe o contador condensado.

5. API JavaScript Programática & Compatibilidade BsMultiSelect

Total compatibilidade drop-in para projetos que utilizam o BsMultiSelect:

JavaScript 
// Instanciação com DexterMultiSelect ou alias BsMultiSelect
const ms = new DexterMultiSelect(document.querySelector('#meuSelect'), {
  color: 'primary',
  collapseAfter: 3,
  showSearch: true,
  showSelectAll: true,
  placeholder: 'Selecione as opções...',
  onChange: (values) => console.log('Valores selecionados:', values)
});

// Métodos disponíveis
ms.selectAll();             // Marca todas as opções
ms.deselectAll();           // Desmarca todas as opções
ms.getSelectedValues();     // ['react', 'vue', ...]
ms.openMenu();              // Abre o menu suspenso
ms.closeMenu();             // Fecha o menu suspenso
