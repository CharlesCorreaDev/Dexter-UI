Avaliação por Estrelas & Reviews Fracionadas

Suíte completa de avaliação por estrelas para o Dexter UI, inspirada e aprimorada a partir do Krajee Bootstrap Star Rating (github.com/kartik-v/bootstrap-star-rating). Elimina totalmente a dependência de jQuery com o controlador nativo DexterRating, suportando preenchimento fracionado de alta precisão (meias estrelas ou frações decimais contínuas por clipping CSS), símbolos vetoriais SVG (estrelas, corações, polegares), botão de limpeza/reset, legendas dinâmicas em badges, modos interativo e somente leitura para avaliações de produtos, 5 tamanhos modulares, suporte às 28 cores oficiais e Dark Mode.

1. Avaliação por Estrelas Básica Interativa

Transforma qualquer <input type="number"> em uma barra interativa de estrelas com suporte a meio ponto (step="0.5") e atualização instantânea da legenda ao mover o cursor do mouse:

Passe o mouse sobre as estrelas para pré-visualizar a nota e clique para fixá-la. Use o botão circular ✕ à esquerda para limpar a avaliação.
HTML 
<!-- Input numérico nativo transformado em Star Rating -->
<input type="number" class="rating" data-dx-rating min="0" max="5" step="0.5" value="3.5" data-dx-color="gold">

5. API Programática JavaScript

Instancie e manipule as avaliações programaticamente com métodos intuitivos e callbacks para eventos:

JavaScript 
// Instanciação programática
const rating = new DexterRating(document.querySelector('#meuRating'), {
  color: 'gold',
  stars: 5,
  step: 0.5,
  showClear: true,
  showCaption: true,
  onRate: (score, instance) => {
    console.log('Nota atribuída:', score);
    dxToast.success('Avaliação Registrada', `Você atribuiu nota ${score}!`);
  },
  onClear: () => console.log('Avaliação zerada')
});

// Métodos disponíveis
rating.rate(4.5);      // Define nota
rating.clear();         // Limpa avaliação
rating.getValue();      // Retorna valor atual (ex: 4.5)
rating.disable();       // Desabilita interação
rating.enable();        // Reabilita interação
