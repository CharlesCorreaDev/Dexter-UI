Componentes WCAG 2.1 AA Bootstrap 3.4 Inspired

Formulários & Controles de Entrada

Estilização moderna de formulários, inputs, textareas, selects, checkboxes, switches e grupos de entrada. Inspirado na ergonomia visual e na consagrada mecânica de foco e sombra interna do Bootstrap 3.4/3.5, combinado organicamente com os 28 temas de cores e design tokens do Dexter UI.

1. Inputs Básicos (.form-control)

A classe .form-control estiliza campos de texto com cantos suavemente arredondados, altura confortável, padding ergonômico e a clássica sombra interna (inset box-shadow) do Bootstrap 3.4. Ao receber foco, projeta um halo brilhante com a cor primária do tema:

Nunca compartilharemos seu e-mail com terceiros.
Use no mínimo 8 caracteres com letras e números. 
<!-- Campo de entrada padrão com label obrigatório -->
<div class="form-group">
  <label class="form-label required" for="email">Endereço de E-mail</label>
  <input type="email" class="form-control" id="email" placeholder="nome@exemplo.com.br">
  <span class="form-text">Texto de instrução ou ajuda auxiliar.</span>
</div>

3. Menus Suspensos (.form-select & DexterSelect), Textareas e Arquivos

O Dexter UI oferece suporte completo a Opções Zebradas (listas alternadas em tom suave para máxima legibilidade conforme ergonomia cognitiva e TDAH), busca instantânea, agrupamento com optgroup e compatibilidade com todos os navegadores modernos e sistemas operacionais via DexterSelect:

Menus Suspensos com Opções Zebradas (.form-select-striped)
Linhas pares recebem #edf2fa no claro e #273549 no escuro.
Ativação instantânea via atributo data-dx-search="true".
Suporta todas as 28 cores oficiais da paleta Dexter UI.
Cor Primária do Tema (#3b5998)
HTML / SCSS / JS 
<!-- Select com Opções Zebradas (.form-select-striped) -->
<select class="form-select form-select-striped">
  <option selected>Selecione uma opção...</option>
  <option value="1">Opção Ímpar (Fundo Branco #ffffff)</option>
  <option value="2">Opção Par (Fundo Zebrado #edf2fa)</option>
  <option value="3">Opção Ímpar (Fundo Branco #ffffff)</option>
</select>

<!-- Select com Busca Integrada e Cores da Paleta -->
<select class="form-select form-select-striped form-select-coral" data-dx-search="true">
  ...
</select>

4. Checkboxes, Radios, Switches, iCheck & Awesome Checkbox

Suíte completa de caixas de seleção, botões de rádio e interruptores reativos inspirados no Awesome Bootstrap Checkbox e iCheck Bootstrap, com suporte a formato circular, tamanhos, estados desativados e todas as 28 cores oficiais do Dexter UI via CSS puro:

1. Controles Padrão do Sistema (.form-check)
2. Awesome Bootstrap Checkbox & Formato Circular (.checkbox-circle)
3. iCheck Bootstrap Suite (.icheck-{cor} & .icheck-circle)
Ideais para cabeçalhos e linhas de tabelas de dados.
HTML / SCSS 
<!-- Awesome Bootstrap Checkbox Circular -->
<div class="checkbox checkbox-circle checkbox-coral">
  <input id="c1" type="checkbox" checked>
  <label for="c1">Opção Circular Coral</label>
</div>

<!-- iCheck Bootstrap com Cores Oficiais -->
<div class="icheck-primary">
  <input type="checkbox" id="ic1" checked />
  <label for="ic1">iCheck Primário</label>
</div>

<!-- Switch Temático Grande -->
<div class="form-check form-switch form-switch-coral form-switch-lg">
  <input class="form-check-input" type="checkbox" role="switch" id="sw1" checked>
  <label class="form-check-label" for="sw1">Ativado</label>
</div>
