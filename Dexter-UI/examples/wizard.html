Assistente de Passos (Step Wizard & Multi-Step)

Suíte completa de formulários multi-etapas e fluxos passo a passo para Dexter UI inspirada no jqueryBootstrapWizard e step-wizard-ui-bootstrap. Totalmente nativa e zero-dependency, com círculos numerados, linha conectora com animação fluida de progresso, checkmarks ao concluir, validação automática de formulários por etapa, layout horizontal e vertical (.wizard-vertical), 28 cores oficiais e Dark Mode.

HTML 
<!-- Estrutura do Assistente de Passos (.wizard) -->
<div class="wizard" data-dx-wizard>
  <!-- Barra de Progresso e Círculos -->
  <div class="wizard-header">
    <div class="wizard-progress">
      <div class="wizard-progress-bar"></div>
    </div>
    <ul class="wizard-steps">
      <li class="wizard-step active">
        <button type="button" class="step-trigger">
          <span class="step-circle"><span class="step-number">1</span></span>
          <div class="step-content">
            <span class="step-title">Conta</span>
          </div>
        </button>
      </li>
      <li class="wizard-step">...</li>
    </ul>
  </div>

  <!-- Painéis de Conteúdo (.wizard-pane) -->
  <div class="wizard-body">
    <div class="wizard-pane active">Etapa 1...</div>
    <div class="wizard-pane">Etapa 2...</div>
  </div>

  <!-- Botões de Navegação -->
  <div class="wizard-footer">
    <button type="button" class="btn btn-outline-secondary wizard-btn-prev">Anterior</button>
    <button type="button" class="btn btn-primary wizard-btn-next">Próximo</button>
    <button type="button" class="btn btn-green wizard-btn-finish" style="display: none;">Finalizar</button>
  </div>
</div>

5. Bootstrap Form Wizard (xonipatino/bootstrap-form-wizard)

Compatibilidade nativa zero-dependência com a API de BootstrapFormWizard (pills com data-bs-toggle="step", painéis role="steppanel", campos externos vinculados via form="..." e data-bfw-in-step="N", retorno à primeira etapa inválida e troca automática para botão de envio na última etapa):

  • 1. Identificação
  • 2. Contato
  • 3. Confirmação
Pronto! Todos os campos dos passos anteriores foram validados com sucesso.
JS 
const wizard = new BootstrapFormWizard('#bfwDemoForm', {
  start: 1,
  useBootstrapValidation: true,
  lang: { backBtn: '< Voltar', nextBtn: 'Próximo >', nextBtnSubmit: 'Enviar' },
  onNext: (step) => console.log('Avançou para passo', step)
});
const instancia = BootstrapFormWizard.forElement('#bfwDemoForm');
console.log(instancia.getCurrentStep());
