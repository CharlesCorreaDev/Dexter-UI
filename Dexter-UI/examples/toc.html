Sumário Automático (Table of Contents - TOC)

Gerador nativo zero-dependência de índice e sumário navegável para páginas longas e documentações, inspirado no clássico bootstrap-toc (Aidan Feldman), com rastreamento ScrollSpy em tempo real, geração inteligente de âncoras/slugs, rolagem suave com compensação de cabeçalho, suporte hierárquico, modo recolhível (collapsible) e integração perfeita às 28 cores oficiais e ao Modo Escuro.

Basta inserir um elemento <nav id="toc" data-toggle="toc"></nav> (ou data-dx-toc) no seu layout para que o DexterToc faça uma varredura automática dos cabeçalhos da página, crie a estrutura aninhada com links clicáveis e ative o rastreador ScrollSpy:

2. Rastreamento ScrollSpy em Tempo Real

O motor de ScrollSpy do DexterToc calcula com alta precisão a linha de corte (offset) da área de leitura, compensando automaticamente barras de topo e menus fixos:

2.1 Compensação de Cabeçalho Sticky (Offset)

Por padrão, o DexterToc aplica uma margem de corte de 80px para que o título nunca fique escondido atrás de barras de navegação fixas. Você pode configurar essa distância via data-toc-offset="100" ou pela opção JavaScript { offset: 100 }.

2.2 Rolagem Suave com Histórico de Navegação

Ao clicar em qualquer item do sumário, a página desliza suavemente até a seção de destino e o hash da URL é atualizado via history.pushState(), permitindo compartilhar links diretos e manter o histórico do navegador íntegro.

2.3 Alta Performance com requestAnimationFrame

O rastreador de rolagem é otimizado com requestAnimationFrame e listeners passivos, garantindo taxa de 60 a 120 FPS mesmo em páginas com centenas de elementos e gráficos complexos.

3. Modo Recolhível Hierárquico (Collapsible)

Para documentações com muitos níveis e seções longas, adicione a classe .toc-collapsible (ou o atributo data-toc-collapsible="true"). Com essa opção ativa, as subseções (H3, H4) ficam recolhidas e só se expandem de forma animada quando o usuário rola até a seção pai correspondente:

Prévia Interativa do Modo Recolhível
Estrutura Recolhível
  • Seção Ativa Expandida
    • Subseção 3.1 Revelada
    • Subseção 3.2 Revelada
  • Próxima Seção (Recolhida)
    • Oculto até ativar
    • Oculto até ativar

O modo recolhível limpa a poluição visual, mantendo o usuário focado no capítulo atual.

4. Geração Inteligente de Slugs e Normalização

Nem todos os cabeçalhos possuem um id="..." manual no HTML. Quando o DexterToc encontra uma tag sem identificador, ele aplica um algoritmo avançado de normalização diacrítica NFD específico para idiomas como o português:

Texto do Cabeçalho ID / Âncora Gerada Automaticamente Tratamento Especial
Configuração de Autenticação #configuracao-de-autenticacao Remove til (ã) e cedilha (ç)
Preço & Condições Especiais! #preco-condicoes-especiais Remove pontuações e símbolos comerciais
Seção 1 (Repetida) #secao-1 e #secao-1-1 Adiciona sufixo numérico para evitar colisões

5. Filtragem de Níveis e Ignorando Seções

Você pode definir exatamente quais tags devem compor o índice e excluir títulos indesejados (como títulos de modais ou cards):

Especificar Níveis de Título

Use data-toc-headings="h2, h3" para incluir apenas seções e subseções principais, ou data-toc-headings="h2, h3, h4" para maior granularidade.

Ignorando Títulos Específicos

Adicione a classe .no-toc ou o atributo data-toc-skip a qualquer cabeçalho que não deva aparecer no sumário.

8. Barra de Ferramentas & API JavaScript

O DexterToc expõe métodos programáticos para controle completo do fluxo de navegação:

JavaScript 
// Obter ou instanciar programaticamente
const toc = DexterToc.getOrCreateInstance('#toc', {
  headings: 'h2, h3',
  offset: 90,
  collapsible: false,
  smoothScroll: true
});

// Navegar para uma seção específica
toc.scrollTo('toc-colors');

// Atualizar o sumário após carregar novo conteúdo AJAX / SPA
toc.refresh();

// Destruir e desvincular listeners
toc.destroy();

9. Referência Completa de Opções e Eventos

Lista exaustiva de atributos HTML e parâmetros suportados:

Opção Atributo HTML Padrão Descrição
target data-toc-target null (auto) Seletor do container a ser escaneado (busca [data-toc-content], main ou body).
headings data-toc-headings 'h2, h3' Seletor de tags de cabeçalho a incluir na lista hierárquica.
offset data-toc-offset 80 Distância em pixels do topo para acionamento do ScrollSpy e parada de rolagem.
collapsible data-toc-collapsible false Quando true, sublistas aninhadas abrem e fecham automaticamente ao rolar.
smoothScroll data-toc-smooth-scroll true Ativa deslizamento suave ao clicar nos links do sumário.
title data-toc-title '' Título exibido no topo do sumário (ex.: "Nesta página").
autoIds — true Gera automaticamente slugs e âncoras para cabeçalhos sem ID.
