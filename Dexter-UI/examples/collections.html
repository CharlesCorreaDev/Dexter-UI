Collections (Listas Materialize)

Listas estruturadas no padrão Materialize CSS integradas ao ecossistema Dexter UI: itens básicos, links interativos com estado ativo, cabeçalhos (.with-header), ações secundárias (.secondary-content), cartões com avatar circular (.avatar), descarte por arrasto horizontal (.dismissable) e suporte completo às 28 cores oficiais e Dark Mode.

1. Coleção Básica (Basic)

A estrutura padrão utiliza ul.collection com itens li.collection-item. Não exige JavaScript e se adapta automaticamente ao tema claro ou escuro.

2. Links & Seleção Ativa (Links)

Use <div class="collection"> com <a class="collection-item"> para criar listas clicáveis. Adicione data-dx-collection-selectable para alternar automaticamente a classe .active ao clicar em qualquer item.

3. Cabeçalhos (.with-header) & Ações Secundárias

Adicione .with-header à coleção com um primeiro item li.collection-header contendo um título (<h4>), e posicione ícones ou badges à direita com .secondary-content.

4. Conteúdo com Avatar (.collection-item.avatar)

Combine .collection-item.avatar com um elemento .circle (imagem ou ícone circular de 42px × 42px), título .title, descrição em <p> e ação secundária alinhada no topo direito.

5. Itens Descartáveis (.dismissable / Swipe & Botão)

Adicione .dismissable (ou .dismissible) a qualquer .collection-item para permitir o descarte arrastando horizontalmente (≥ 90px com Pointer Events) ou clicando no botão acessível .collection-dismiss-btn.

6. Cores Oficiais (.collection-{cor}) & Variantes

Aplique qualquer uma das 28 cores da paleta oficial Dexter UI via .collection-{cor} para personalizar o estado .active, links secundários e fundo de avatares. Combine ainda com .collection-sm (compacta) ou .collection-flush (sem bordas laterais).

7. Exemplos de Código & API JavaScript

Estrutura HTML semântica compatível com o Materialize CSS e eventos customizados do módulo DexterCollection:

HTML 
<!-- Coleção com cabeçalho, avatar e ação secundária -->
<ul class="collection with-header collection-teal">
  <li class="collection-header"><h4>Equipe</h4></li>
  <li class="collection-item avatar">
    <img src="avatar.png" alt="Usuário" class="circle">
    <span class="title">Charles Corrêa</span>
    <p>Primeira linha<br>Segunda linha</p>
    <a href="#!" class="secondary-content">Ver</a>
  </li>
  <li class="collection-item dismissable">
    <div>
      <span>Item descartável</span>
      <button type="button" class="collection-dismiss-btn" aria-label="Remover">&times;</button>
    </div>
  </li>
</ul>
JAVASCRIPT 
// Escutar eventos de seleção e descarte
document.addEventListener('dexter.collection.select', (e) => {
  console.log('Selecionado:', e.detail.item.textContent.trim());
});

document.addEventListener('dexter.collection.dismiss', (e) => {
  console.log('Item removido na direção:', e.detail.direction);
});

// Descartar programaticamente um item específico
const item = document.querySelector('#meu-item');
DexterCollection.dismiss(item, 1);
