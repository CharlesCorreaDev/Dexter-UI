Seletor Numérico Stepper (Input Spinner)

Suíte completa de seletores numéricos com botões de incremento e decremento para o Dexter UI, inspirada e aprimorada a partir do bootstrap-input-spinner (github.com/shaack/bootstrap-input-spinner). Substitui os seletores numéricos inconsistentes dos navegadores por um componente moderno, responsivo e touch-friendly, trazendo aceleração contínua por clique longo, formatação internacional, prefixos e sufixos monetários ou métricos, layout empilhado vertical (.spinner-stacked), compatibilidade com as 28 cores oficiais e Dark Mode.

1. Seletor Numérico Básico Horizontal

Transforma qualquer <input type="number"> em um grupo harmonioso com botões - e +. Basta adicionar o atributo data-dx-spinner:

Pressione e segure o botão + para ver a aceleração contínua automática.
HTML 
<!-- Input numérico nativo transformado em Input Spinner -->
<input type="number" data-dx-spinner min="1" max="100" step="1" value="1" data-dx-color="primary">

5. API JavaScript Programática & Compatibilidade InputSpinner

Total compatibilidade drop-in para projetos que utilizam o InputSpinner:

JavaScript 
// Instanciação programática com DexterInputSpinner ou alias InputSpinner
const spinner = new DexterInputSpinner(document.querySelector('#meuNumero'), {
  min: 0,
  max: 100,
  step: 1,
  prefix: 'R$ ',
  color: 'primary',
  onChange: (val) => console.log('Novo valor:', val)
});

// Métodos disponíveis
spinner.stepUp();         // Incrementa valor
spinner.stepDown();       // Decrementa valor
spinner.setValue(50);     // Define valor específico
spinner.getValue();       // Retorna valor numérico
