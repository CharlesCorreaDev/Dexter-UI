Modais & Diálogos Dinâmicos (Modals)

Suíte completa de modais e janelas de diálogo para Dexter UI, com suporte a estrutura HTML estática e criação dinâmica via JavaScript inspirada no bootstrap-show-modal (shaack). Permite disparar caixas de alerta (showAlert), confirmações assíncronas com Promises (showConfirm), caixas de entrada rápida (showPrompt) e modais personalizados (showModal) sem escrever uma única linha de marcação no DOM.

1. Diálogos Dinâmicos via JavaScript (ShowModal Suite)

Elimina a necessidade de código HTML estático repetitivo. Os modais são criados dinamicamente no DOM e destruídos automaticamente ao fechar:

Dispare Diálogos Dinâmicos Imediatos:
Resultado da Ação:
JavaScript 
// 1. Alerta simples com botão OK
dexter.showAlert({
  title: "Notificação do Sistema",
  body: "Seus dados foram sincronizados com sucesso no Dexter UI!"
});

// 2. Confirmação assíncrona com Promise
const confirmou = await dexter.showConfirm({
  title: "Excluir Registro?",
  body: "Esta ação é irreversível. Deseja realmente excluir?",
  textConfirm: "Sim, Excluir",
  classConfirm: "btn-danger",
  textCancel: "Cancelar"
});
if (confirmou) {
  console.log("Item excluído com sucesso!");
}

// 3. Prompt de entrada rápida de texto
const nome = await dexter.showPrompt({
  title: "Identificação",
  body: "Por favor, digite seu nome completo:",
  placeholder: "Ex: Charles Corrêa"
});
console.log("Nome digitado:", nome);

// 4. Modal dinâmico completo com botões personalizados
dexter.showModal({
  title: "Modal Dinâmico Personalizado",
  body: "
Criado via JavaScript sem marcação HTML prévia!
",
  headerClass: "modal-header-coral",
  size: "modal-md",
  buttons: [
    { label: "Fechar", class: "btn-outline-secondary" },
    { label: "Salvar Alterações", class: "btn-coral", onClick: (e, modal) => {
      console.log("Salvo!");
    }}
  ]
});
