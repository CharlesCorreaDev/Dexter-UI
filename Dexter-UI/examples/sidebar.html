Barra Lateral Administrativa (Admin Sidebar)

Menu administrativo completo inspirado no Nelh/Next-sidebar, reconstruído 100% em Vanilla JS e CSS moderno (zero jQuery, zero PerfectScrollbar). Inclui recolhimento para trilho de ícones (70px), expansão automática ao passar o mouse (hover-expand), acordeão multinível sem limite de profundidade, pesquisa expansível no topo, tema claro/escuro e 28 cores oficiais.

1. Demonstração Interativa (.app.app-contained)

Clique no botão ☰ na barra superior para alternar entre expandida e recolhida. No desktop recolhido, passe o mouse sobre a barra lateral para expandir temporariamente!
