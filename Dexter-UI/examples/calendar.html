Calendário de Eventos (Event Calendar)

Componente interativo zero-dependência inspirado no jquery-bs-calendar (ThomasDev-de), com suporte a localização via Intl.DateTimeFormat, contadores de compromissos, popover flutuante ao passar o cursor, painel externo de eventos, uso inline ou em dropdown/offcanvas e todas as 28 cores oficiais com Modo Escuro nativo.

JS
const cal = new DexterCalendar('#meuCalendario', {
  locale: 'pt-BR',
  eventListContainer: '#listaEventos',
  events: [
    { id: 1, title: 'Sprint Review', start: '2026-11-25 14:00:00', end: '2026-11-25 15:00:00', description: 'Alinhamento semanal' }
  ]
});
cal.setDate('2026-12-25');
