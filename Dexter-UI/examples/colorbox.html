3. Exemplos de Código (API Vanilla JS & Declarativa)

JS
// 1. Ativação por seletor (compatível com Jack Moore Colorbox)
colorbox('a.gallery1', { rel: 'gallery1', transition: 'elastic', theme: 'example5' });

// 2. Slideshow automático
colorbox('.slideshow', { rel: 'group', slideshow: true, slideshowSpeed: 2500 });

// 3. Conteúdo Inline & HTML direto
colorbox({ inline: true, href: '#meuBloco', width: '500px' });
colorbox({ html: '<h4>HTML Direto</h4><p>Renderizado sem dependências!</p>' });

// 4. Iframe e Callbacks
colorbox({
  iframe: true,
  href: 'https://example.com',
  width: '80%',
  height: '80%',
  onComplete: function () { console.log('Colorbox carregado!'); }
});
