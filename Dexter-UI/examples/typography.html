1. Altura de Linha / Line Height

Parágrafo de destaque com a classe .lead.

.lh-1: Altura de linha mínima (1.0) para títulos curtos e badges.

.lh-sm / .lh-tight: Altura de linha compacta (1.25).

.lh-base: Altura de linha padrão (1.5) recomendada para leitura contínua.

.lh-lg / .lh-loose: Altura de linha expandida (1.75).

2. Famílias de Fonte / Font Family

Tokens semânticos e categorias genéricas padronizadas:

.font-body / .font-sans: Inter (ou sans-serif do sistema) para texto corrido.

.font-title: Poppins (ou sans-serif geométrica) para títulos e destaques.

.font-code / .font-monospace: JetBrains Mono (ou monospace) para códigos e dados técnicos.

.font-serif: Georgia, Cambria, Times New Roman para tipografia serifada clássica.

3. Tamanho de Fonte / Font Size

Escala de .fs-1 a .fs-6 com suporte a variantes responsivas (ex: .fs-5 .fs-lg-2):

.fs-1: Texto de tamanho 1 (2.5rem fluida)

.fs-2: Texto de tamanho 2 (2rem fluida)

.fs-3: Texto de tamanho 3 (1.75rem fluida)

.fs-4: Texto de tamanho 4 (1.5rem)

.fs-5: Texto de tamanho 5 (1.25rem)

.fs-6: Texto de tamanho 6 (1rem)

.small / <small>: Texto reduzido (0.875em)

4. Estilo de Fonte / Font Style

Variações de inclinação tipográfica:

.fst-italic: Texto em itálico com glifos cursivos desenhados.

.fst-normal: Texto normal sem inclinação (útil para anular itálicos de <em> ou <i>).

.fst-oblique: Texto oblíquo inclinado artificialmente.

5. Peso de Fonte / Font Weight

Suporte a nomes semânticos e valores numéricos exatos (100 a 900):

.fw-light / .fw-300: Peso Light (300)

.fw-normal / .fw-400: Peso Normal (400)

.fw-medium / .fw-500: Peso Médio (500)

.fw-semibold / .fw-600: Peso Semibold (600)

.fw-bold / .fw-700: Peso Bold (700)

.fw-extrabold / .fw-800: Peso Extrabold (800)

.fw-bolder: Relativamente mais espesso

.fw-lighter: Relativamente mais leve

6. Alinhamento de Texto / Text Alignment

Alinhamentos lógicos com suporte a variantes responsivas (ex: .text-center .text-md-start):

.text-start: Alinhado no início (esquerda em LTR, direita em RTL).

.text-center: Alinhado no centro.

.text-end: Alinhado no fim (direita em LTR, esquerda em RTL).

.text-justify: Alinhamento justificado distribuindo o espaço entre as palavras ao longo de toda a linha.

7. Transformação e Decoração / Text Transform & Decoration

Transformação (Transform)

.text-lowercase: TEXTO EM MINÚSCULAS

.text-uppercase: texto em maiúsculas

.text-capitalize: texto com iniciais maiúsculas

.text-none: anula transformações herdadas

Decoração (Decoration)

.text-decoration-underline: Sublinhado

.text-decoration-line-through: Riscado

.text-decoration-overline: Linha superior

.text-decoration-none: Sem decoração

8. Quebra e Distribuição de Linhas / Text Wrapping

.text-pretty (CSS Moderno):

Evita palavras órfãs isoladas na última linha de parágrafos extensos através de cálculo balanceado inteligente do motor de renderização.

.text-balance (Títulos equilibrados):

Distribui o comprimento das linhas harmoniosamente em títulos e chamadas

.text-truncate (Truncamento com reticências em 1 linha):

Este é um texto muito longo que será truncado automaticamente com reticências (...) sem quebrar a linha.

.text-nowrap (Sem quebra de linha):

Texto forçado a permanecer estritamente em uma única linha horizontal contínua sem quebras.

.text-break (Quebra de palavras longas):

supercalifragilisticexpialidocious_texto_sem_espacos_que_quebra_em_qualquer_ponto
