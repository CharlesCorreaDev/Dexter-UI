Tags, Badges & Autocomplete Multiselect

Suíte completa de seleção de tags, badges interativas e autocomplete multiselect para o Dexter UI, inspirada e aprimorada a partir do bootstrap5-tags (github.com/lekoala/bootstrap5-tags). Zero dependência de jQuery ou bibliotecas externas com o controlador nativo DexterTags, trazendo chips com botão de remoção, menu dropdown de sugestões com navegação fluida por teclado (setas, Enter, Tab e Backspace), criação livre de tags (allowNew), limites máximos (max), estilos visuais (sólido, suave/soft e contorno), integração às 28 cores oficiais do framework e suporte a Dark Mode.

1. Badges & Chips Standalone

Emblemas compactos e chips de estado disponíveis nos formatos sólido, suave (soft) e contorno (outline), com suporte a pílula (.badge-pill), ponto de status (.badge-dot) e botão de remoção (.badge-close):

Badges com Ponto Indicador (.badge-dot) & Pílula (.badge-pill)

2. Seleção Múltipla com Autocomplete via <select multiple>

Transforma qualquer <select multiple> nativo em um campo interativo de tags com busca inteligente. Basta adicionar o atributo data-dx-tags. A seleção permanece sincronizada com o elemento de formulário nativo.

Experimente clicar no campo, usar as setas do teclado para navegar pelas sugestões ou apagar tags com Backspace.
HTML 
<!-- Select Múltiplo nativo transformado em Tag Input interativo -->
<select class="form-tags" multiple data-dx-tags data-dx-color="primary" placeholder="Adicionar tecnologias...">
  <option value="php" selected>PHP</option>
  <option value="javascript" selected>JavaScript</option>
  <option value="typescript" selected>TypeScript</option>
  <option value="python">Python</option>
  <option value="rust">Rust</option>
</select>

3. Criação Livre de Novas Tags (Free Tagging)

Permite aos usuários digitar qualquer termo e transformá-lo imediatamente em uma nova tag pressionando Enter ou vírgula ,. Ativado com data-allow-new="true":

Digite qualquer termo livremente. O separador padrão aceita vírgula e Enter.
HTML 
<!-- Input com criação livre de novas tags e tema Coral -->
<input type="text" class="form-tags" data-dx-tags data-dx-color="coral" data-allow-new="true" value="design system, ux" placeholder="Digite uma tag...">

3b. Recursos Avançados & Compatibilidade Tagin (erwinheldy/tagin)

Incorpora e expande os diferenciais da biblioteca tagin: transformação automática de texto (como #hashtags via barra de espaço ou lowercase), colagem em lote (paste com separador automático de texto copiado) e duplo clique em qualquer tag para reabrí-la para edição:

Digite uma palavra e aperte a barra de espaço para prefixar automaticamente com #.
Dê duplo clique em uma tag para editá-la. Cole textos como maçã, banana, uva para inserir em lote.
HTML / JS 
<!-- Compatibilidade total com a classe .tagin e transformação de hashtags -->
<input type="text" class="tagin" data-transform="hashtag" data-separator=" ">

<!-- Inicialização compatível com a API do Tagin -->
<script>
  const tagin = new Tagin(document.querySelector('.meu-input'), {
    separator: ' ',
    duplicate: false,
    transform: 'hashtag'
  });
</script>

Aprovados
Bloqueados
Separar por ; ou '

7. API Programática JavaScript

Controle o componente programaticamente de forma simples e direta com a classe DexterTags:

JavaScript 
// Instanciação programática
const myTags = new DexterTags(document.querySelector('#meuElemento'), {
  color: 'primary',
  allowNew: true,
  max: 5,
  badgeStyle: 'soft',
  suggestions: ['React', 'Vue', 'Angular', 'Svelte', 'SolidJS'],
  onTagAdd: (tag, allTags) => console.log('Adicionada:', tag),
  onTagRemove: (tag, allTags) => console.log('Removida:', tag),
  onChange: (allTags) => console.log('Tags atuais:', allTags)
});

// Métodos disponíveis
myTags.addTag('Next.js');
myTags.removeTag('React');
myTags.getValues(); // ['Next.js', ...]
myTags.clear();     // Limpa tudo
