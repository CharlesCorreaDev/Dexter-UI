Menus Suspensos Multiníveis (Multi-Level Dropdowns)

Suíte completa de menus suspensos multiníveis baseada na arquitetura de dallaslu/bootstrap-5-multi-level-dropdown, com suporte a aninhamento infinito de submenus laterais (.dropend e .dropstart), acionamento por clique ou hover suave (.dropdown-hover), integração com todas as 28 cores oficiais da paleta e suporte nativo ao Dark Mode.

1. Dropdown Multinível (Padrão Dallas Lu)

Permite aninhar submenus em múltiplos níveis (Nível 1, 2, 3...) utilizando classes canônicas do Bootstrap (.dropend dentro de <li>) com setas indicadoras automáticas:

  • Gestão Empresarial
  • Dashboard Geral
  • Relatórios Financeiros
  • Módulos do Sistema
    • Vendas & CRM
    • Faturamento & NF-e
    • Configurações Avançadas
      • Webhooks & API
      • Integração SMTP
      • Backups em Nuvem
    • Controle de Estoque
  • Segurança & Auditoria
  • Módulo Legado (Desativado)
<!-- Dropdown Multinível no padrão Dallas Lu -->
<div class="dropdown">
  <button class="btn btn-primary dropdown-toggle" type="button" data-bs-toggle="dropdown">
    Menu Multinível
  </button>
  <ul class="dropdown-menu">
    <li><a class="dropdown-item" href="#">Ação 1</a></li>

    <!-- Nível 2 (Submenu lateral à direita) -->
    <li>
      <div class="dropdown dropend">
        <a class="dropdown-item dropdown-toggle" href="#" data-bs-toggle="dropdown">Mais Opções</a>
        <ul class="dropdown-menu">
          <li><a class="dropdown-item" href="#">Sub-item 2.1</a></li>

          <!-- Nível 3 (Aninhamento infinito) -->
          <li>
            <div class="dropdown dropend">
              <a class="dropdown-item dropdown-toggle" href="#" data-bs-toggle="dropdown">Nível 3</a>
              <ul class="dropdown-menu">
                <li><a class="dropdown-item" href="#">Sub-item 3.1</a></li>
              </ul>
            </div>
          </li>
        </ul>
      </div>
    </li>
  </ul>
</div>

2. Abertura por Hover Suave (.dropdown-hover)

Adicione a classe .dropdown-hover para abrir o menu e os submenus automaticamente ao passar o cursor do mouse, com delay inteligente que previne fechamentos indesejados:

  • Serviços em Nuvem
  • Bancos de Dados
    • PostgreSQL Gerenciado
    • Redis Cache Cluster
    • ClickHouse Analytics
  • Monitoramento Datadog
<!-- Dropdown acionado por Hover -->
<div class="dropdown dropdown-hover">
  <button class="btn btn-secondary dropdown-toggle" type="button">
    Passe o mouse
  </button>
  <ul class="dropdown-menu">
    <li><a class="dropdown-item" href="#">Item 1</a></li>
    <li>
      <div class="dropdown dropend">
        <a class="dropdown-item dropdown-toggle" href="#">Submenu Hover</a>
        <ul class="dropdown-menu">
          <li><a class="dropdown-item" href="#">Item 2.1</a></li>
        </ul>
      </div>
    </li>
  </ul>
</div>

3. Submenu à Esquerda (.dropstart)

Para layouts com menus posicionados no lado direito da tela, use .dropstart para que os submenus se expandam para o lado esquerdo:

  • Meu Perfil
  • Preferências
    • Notificações
    • Privacidade
    • Chaves de API
  • Sair da Conta
<!-- Submenu expandindo para a esquerda com .dropstart -->
<ul class="dropdown-menu dropdown-menu-end">
  <li>
    <div class="dropdown dropstart">
      <a class="dropdown-item dropdown-toggle" href="#">Preferências</a>
      <ul class="dropdown-menu">
        <li><a class="dropdown-item" href="#">Sub-item à Esquerda</a></li>
      </ul>
    </div>
  </li>
</ul>

4. Paleta Oficial em Dropdowns (.dropdown-menu-{cor})

Personalize instantaneamente o menu aplicando a classe de cor da paleta do Dexter UI. Cada variante tonal estiliza a borda superior de 3px, divisores, cabeçalhos, efeitos de hover e estados ativos:

  • Tema Coral
  • Item Ativo
  • Hover com Tom Coral
  • Submenu Coral
    • Sub-item Coral
  • Tema Verde
  • Aprovado
  • Exportar Planilha
  • Relatórios
    • Relatório Mensal
  • Tema Roxo
  • Analytics
  • Faturamento
  • Tema Midnight
  • Logs de Segurança
  • Tokens OAuth
  • Menu Sólido
  • Fundo Colorido
  • Hover Translúcido
<!-- Menus com bordas e destaques tonais da paleta -->
<ul class="dropdown-menu dropdown-menu-coral">...</ul>
<ul class="dropdown-menu dropdown-menu-green">...</ul>
<ul class="dropdown-menu dropdown-menu-purple">...</ul>
<ul class="dropdown-menu dropdown-menu-midnight">...</ul>

<!-- Menus totalmente preenchidos em cor sólida -->
<ul class="dropdown-menu dropdown-menu-solid-primary">...</ul>
